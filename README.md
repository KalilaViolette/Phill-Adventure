# Phill's Adventure to the Ice Cream Cave

A pixel-art runner starring Phill, a green plushy. It's late, the house is asleep, and Phill can't stop thinking about the giant sundae hidden deep in the Ice Cream Cave. Help him waddle there.

**Play it:** https://kalilaviolette.github.io/Phill-Adventure/

- Space / Up: jump (hold for higher)
- Down: slide
- P: pause, M: mute
- On phones: the Jump and Slide buttons under the game

Everything (art, music and sound) is in the single `index.html`, so no build step and no other files are needed.
